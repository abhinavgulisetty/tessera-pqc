Quick Start

Installation 
pip install tessera-pqc
Kyber Key Exchange 
import tessera as t

pk, sk = t.kyber_keygen("768")
ct, shared1 = t.kyber_encaps(pk, "768")
shared2 = t.kyber_decaps(sk, ct, "768")
assert shared1 == shared2
Side-Channel Attack 
import tessera as t

data = t.generate_traces(n_traces=1000, trace_length=32)
result = t.run_cpa(data["traces"], data["plaintexts"])
print(f"Recovered: {result['recovered_key']}")
CLI Usage 
tessera kyber --variant 768
tessera dilithium --variant 3
tessera attack cpa --traces 1000
tessera tvla --traces 5000
